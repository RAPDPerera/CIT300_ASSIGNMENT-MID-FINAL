## Stack Functionality
The Stack follows LIFO (Last In, First Out).

- push() — Adds an item to the top.
- pop() — Removes the top item.
- peek() — Shows the top item without removing it.
- display() — Displays stack items.
- Handles attempts to use an empty stack.

## Queue Functionality
The Queue follows FIFO (First In, First Out).

- Adds items to the rear of the queue.
- Removes items from the front of the queue.
- Shows the front item without removing it.
- Displays queue items.
- Handles attempts to remove an item from an empty queue.

Use the exact method names defined in Queue.java when integrating the code.

## Testing
The Stack and Queue test programs were run in VS Code. The test output showed that items were added and removed in the expected order, and empty Stack/Queue cases displayed suitable messages.
