CIT300 Data Structure and Graph Performance Analyzer

1. Project Description

The Data Structure and Graph Performance Analyzer is a Java-based console application developed for the CIT300 Data Structures and Algorithms Graded Practical Assignment 2.

The system demonstrates the implementation and use of different data structures, searching algorithms, graph traversal techniques, and performance comparison.

5. How to Run the Application

1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the main project folder in Visual Studio Code or a terminal.
4. Navigate to the folder containing the src directory.
5. Compile the Java source files:

javac -d out src/*.java

6. Run the application:

java -cp out Main

    Alternatively, run compile_and_run.bat on Windows.
